# Player Sprites Directory

Place Sophie's 16-bit transparent sprite sheet image here:
- `sophie_swing.png`

Recommended Format:
- Horizontal sprite sheet containing 8 frames (each frame 48x48 pixels, transparent background):
  - Frame 0: Address pose 1
  - Frame 1: Address pose 2 (wiggle)
  - Frame 2: Backswing low
  - Frame 3: Backswing mid
  - Frame 4: Top of swing apex
  - Frame 5: Downswing acceleration
  - Frame 6: Impact snap frame (triggers ball launch)
  - Frame 7: High follow-through pose

If absent, the engine automatically generates Sophie's 16-bit procedural sprite sheet fallbacks!
